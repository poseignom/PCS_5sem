### Использованные виджеты:

- **StatelessWidget** - для статичного интерфейса
- **MaterialApp** - корневой виджет приложения
- **Scaffold** - базовый каркас страницы
- **AppBar** - верхняя панель навигации
- **Column** - вертикальное расположение
- **Row** - горизонтальное расположение
- **Text** - текстовые элементы
- **Container** - контейнеры с фоном
- **ElevatedButton** - кнопка с заливкой
- **OutlinedButton** - контурная кнопка
- **Icon** - иконки
- **Card** - карточка с тенью
- **SizedBox** - отступы и пространство
- **Padding** - внутренние отступы
- **Center** - выравнивание по центру

### Ключевые элементы кода:

// Текст со стилями
Text(
  'Добро пожаловать в Flutter!',
  style: TextStyle(
    fontSize: 24,
    fontWeight: FontWeight.bold,
    color: Colors.blue,
  ),
)

// Контейнер с кастомным цветом
Container(
  color: Color(0xFF4CAF50),
  child: Center(
    child: Text('Кастомный цвет'),
  ),
)

// Горизонтальное расположение иконок
Row(
  mainAxisAlignment: MainAxisAlignment.spaceEvenly,
  children: [
    Icon(Icons.star, color: Colors.amber),
    Icon(Icons.favorite, color: Colors.red),
  ],
