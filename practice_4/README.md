### Использованные виджеты и свойства:

- **StatefulWidget** - для управления состоянием
- **setState** - для обновления состояния и интерфейса
- **GestureDetector** - для обработки жестов (долгое нажатие)
- **Container** - для стилизации и отступов
- **Row** - для горизонтального расположения кнопок
- **Column** - для вертикального расположения элементов
- **SizedBox** - для создания отступов
- **BoxDecoration** - для оформления контейнеров
- **LinearGradient** - для градиентного фона
- **BoxShadow** - для добавления теней
- **IconButton** - для кнопок с иконками
