### Созданные экраны:

1. **Экран приветствия**
   - Логотип приложения
   - Приветственный текст
   - Кнопка "Начать"

2. **Главный экран**
   - Верхняя панель с названием приложения
   - Список карточек заметок
   - Кнопка "+" для добавления новой заметки

3. **Экран добавления заметки**
   - Поле ввода заголовка
   - Поле ввода текста заметки
   - Кнопка "Сохранить"
   - Кнопка "Назад"

### Навигация:
- Кнопка "Начать" → переход на главный экран
- Кнопка "+" → переход на экран добавления
- Кнопка "Сохранить" → возврат на главный экран
- Кнопка "Назад" → возврат на главный экран
