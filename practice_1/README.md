1. **Проблема**: Ошибка "Unable to find git in your PATH" при создании проекта

2. **Проблема**: Android toolchain - cmdline-tools component is missing
   **Решение**: Установлены Android SDK Command-line Tools через SDK Manager

3. **Проблема**: Android license status unknown
   **Решение**: Выполнена команда `flutter doctor --android-licenses` с правами администратора
